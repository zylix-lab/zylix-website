# Zylix Creative House — V4 Multi-page Architecture

This version converts the single-page concept into a real multi-page static website while keeping the V3.1 green theme.

## Main routes
- `/` Home
- `/work/` All work
- `/capabilities/` Capabilities
- `/about/` About
- `/start-project/` Project brief
- `/contact/` Contact

## Core
- `/studio/` Zylix Studio
- `/edit-house/` Zylix Edit House
- `/ecommerce/` E-commerce, with REVYT link
- `/tools/` Web, AI & Tools

## Capability pages
- `/services/content-video/`
- `/services/brand-design/`
- `/services/marketing/`
- E-commerce reuses `/ecommerce/`
- Web / AI / Tools reuses `/tools/`
- Odd Brief uses `/start-project/`

## Work collections
- `/work/healthcare/`
- `/work/food/`
- `/work/salon/`
- `/work/posters/`
- `/work/websites/`
- Edit House is its own dedicated portfolio route at `/edit-house/`

## Before launch
The site still needs real media, confirmed statistics and contact links. The Project Brief backend is a UI shell until Google Apps Script is connected. Replace `YOUR-DOMAIN-HERE` in `sitemap.xml` before publishing.
